# 서비스 기획서 — 루틴메이트 (RoutineMate)

## 1. 서비스 개요

- **서비스명:** 루틴메이트
- **한 줄 소개:** 목표·시간·컨디션을 입력하면 AI가 오늘 실천 가능한 미니 루틴을 추천해주는 서비스
- **타겟 사용자:** 습관을 만들고 싶지만 계획이 자주 무너지는 직장인·학생
- **핵심 가치:** "오늘, 지금 가진 시간과 컨디션으로 할 수 있는 것"에 집중해 실행 장벽을 낮춘다.

## 2. 페이지 / 섹션 구성

단일 페이지(index.html) 안에서 상단 내비게이션으로 이동하는 4개 섹션 구조입니다.

| 섹션 | 앵커 | 내용 |
|---|---|---|
| 홈 | `#home` | 서비스 핵심 메시지와 CTA(루틴 추천받기 버튼) |
| 서비스 소개 | `#about` | 입력 → 추천 → 실천의 3단계 설명 |
| AI 루틴 추천 | `#recommend` | 목표/시간/컨디션 입력 폼 + AI 결과 표시 |
| 문의하기 | `#contact` | 이름/이메일/메시지 입력 폼 |

모바일에서는 햄버거 메뉴로 동일한 내비게이션을 제공합니다.

## 3. AI 기능 설계

- **입력값**
  - 목표 (텍스트, 필수) — 예: "아침에 일찍 일어나기"
  - 오늘 사용 가능한 시간 (선택형: 5분 / 15분 / 30분 / 1시간 이상, 필수)
  - 오늘 컨디션 (선택형: 좋음 / 보통 / 피곤함, 필수)
- **출력값**
  - 루틴 이름 1줄
  - 실행 순서 2~4단계
  - 컨디션을 고려한 한 줄 응원 메시지
- **사용자에게 제공하는 가치**
  - 매번 새로 계획을 짜야 하는 부담 없이, 오늘 상황에 맞는 실행안을 즉시 받는다.
- **실패 처리 기준**
  1. **빈 입력(필수값 누락):** 클라이언트/서버 양쪽에서 검증. "목표, 시간, 컨디션을 모두 입력해주세요." 안내 후 요청을 보내지 않음.
  2. **API 오류(4xx/5xx):** 서버에서 502/500 응답 시 "잠시 후 다시 시도해주세요." 안내 표시, 원본 오류는 노출하지 않음.
  3. **지연/타임아웃:** 클라이언트에서 15초 타임아웃 설정, 초과 시 "응답이 지연되고 있습니다" 안내 표시.

## 4. 화면 흐름

```
[홈] --CTA 클릭--> [AI 루틴 추천]
  ↳ 목표/시간/컨디션 입력
  ↳ 제출 → 로딩 상태 표시
  ↳ 성공: 결과 카드 표시
  ↳ 실패: 케이스별 안내 메시지 표시 (재시도 가능)
```

## 5. 반응형 기준

- 데스크톱(≥ 1024px): 3열 카드 그리드, 가로 내비게이션
- 모바일(≤ 720px): 1열 스택 레이아웃, 햄버거 메뉴
- 최소 2개 화면 크기(데스크톱/모바일)에서 레이아웃 깨짐 여부를 직접 확인합니다.

## 6. 향후 확장 아이디어 (보너스 과제 연계)

- 추천받은 루틴을 이메일/노코드 자동화 도구로 저장해 "오늘의 루틴" 리마인드 발송
- 다크 모드 토글 추가 및 방문자 분석(예: Vercel Analytics) 연동
